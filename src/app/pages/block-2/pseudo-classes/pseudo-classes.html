Разница между псевдоклассами и псевдоэлементами

Простое мнемоническое правило для запоминания:

Псевдокласс ( Hover, Active, Focus, Nth-child )

Выбирает **целиком существующий элемент**, когда он удовлетворяет определенному временному состоянию или условию расположения. Пишется через **одно** двоеточие (:).

Псевдоэлемент ( Before, After, Selection )

Создает **новую виртуальную часть** элемента или выбирает только кусочек его содержимого. Пишется через **два** двоеточия (::).

Интерактивные псевдоклассы и псевдоклассы состояний

Они динамически реагируют на поведение и действия пользователя на странице:

:link

Непосещенная ссылка. Находит любые ссылки (теги <a> с атрибутом href), по которым пользователь ещё ни разу не переходил с этого браузера.

:visited

Посещенная ссылка. Выбирает ссылки, по которым пользователь уже переходил. В целях **конфиденциальности пользователей** современные браузеры строго ограничивают стили для :visited: вы можете менять только цвет текста и фонов, чтобы сторонние сайты не могли тайно сканировать историю ваших просмотров.

:hover

Наведение мыши. Активируется в тот момент, когда курсор пользователя оказывается над границами элемента. Широко используется для плавных анимаций ховеров кнопок и ссылок.

:active

Элемент в процессе активации. Состояние нажатия. Срабатывает в момент удержания левой кнопки мыши на кнопке или ссылке до того, как кнопка будет отпущена.

:focus и :focus-visible

Элемент в фокусе. Псевдокласс :focus срабатывает всегда, когда элемент активен для ввода (например, кликнутое текстовое поле). Псевдокласс :focus-visible — более современный, он рисует рамку фокуса **только при навигации с клавиатуры** (кнопкой Tab), не раздражая пользователей мыши лишними обводками.

Позиционные псевдоклассы (структурные)

Позволяют выбирать элементы на основе их расположения внутри родителя без необходимости присваивать им классы:

:first-child и :last-child

Выбирают самый первый или самый последний элемент в своем родительском контейнере. Часто используются, чтобы убрать нижний отступ (margin-bottom) у последнего абзаца в карточке.

:nth-child(формула)

Мощный селектор, который выбирает элементы по математической формуле an+b, где n — это счетчик, последовательно принимающий значения от 0 до бесконечности.

:not(селектор)

Псевдокласс отрицания. Выбирает все элементы, которые НЕ соответствуют указанному селектору. Например, правило li:not(:last-child) применит стили ко всем элементам списка, кроме самого последнего.
