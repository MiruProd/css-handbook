Сравнительный анализ режимов position

Каждое значение изменяет точку отсчета координат элемента и его влияние на окружающие теги:

1. static

Поведение по умолчанию. Элемент находится в нормальном (естественном) потоке документа. Свойства top, right, bottom, left и z-index на него никак не влияют.

2. relative (Относительное)

Элемент сдвигается относительно своего исходного положения в потоке. Важно: физически элемент смещается, но браузер продолжает резервировать его исходное место в структуре страницы, поэтому соседние блоки не сдвигаются.

3. absolute (Абсолютное)

Элемент полностью вырывается из нормального потока. Другие блоки ведут себя так, будто его вовсе нет. Он позиционируется относительно ближайшего предка с position отличным от static. Если такого предка нет, точкой отсчета становится окно просмотра (viewport).

4. fixed (Фиксированное)

Похоже на absolute, но элемент всегда позиционируется относительно окна браузера (viewport). Он вырван из потока и остается на своем месте даже при прокрутке всей веб-страницы. Часто применяется для плавающих кнопок «Вверх» или фиксированных шапок.

5. sticky (Липкое)

Гибридный режим. Элемент ведет себя как relative, пока не достигнет указанного порога скролла (например, top: 20px). После этого он «залипает» на месте как fixed. Элемент остается липким только внутри границ своего непосредственного родительского контейнера.

Индекс наложения (z-index) и Stacking Context

Свойство z-index управляет тем, в каком порядке элементы накладываются друг на друга по виртуальной оси Z (ближе или дальше от взгляда пользователя).

Свойство z-index работает только для элементов, у которых значение position отличается от стандартного static (например, задано relative, absolute, fixed или sticky)! На статичных элементах оно полностью игнорируется браузером.

Поведение z-index

  • По умолчанию элементы, идущие ниже в HTML-коде, перекрывают те, что объявлены выше.
  • Элемент с бо́льшим числом z-index отображается поверх элемента с меньшим индексом.
  • Значение может быть отрицательным (например, z-index: -1), чтобы увести элемент на задний план под текст.

Контекст наложения (Stacking Context)

  • Контекст наложения создается определенными свойствами (position + z-index, opacity < 1, transform, filter).
  • Внутри контекста дочерние элементы сравниваются только друг с другом.
  • Высокий z-index дочернего элемента не поможет перекрыть внешний блок, если родительский контекст наложения находится ниже по оси Z.
