12. Flexbox Layout

Flexbox (Flexible Box Layout) — это одномерный метод разметки, который позволяет распределять пространство между элементами и выравнивать их по горизонтали или вертикали, даже если их размеры неизвестны или динамичны.

Основные концепции Flexbox

Ключевая идея Flexbox заключается в наличии родительского контейнера (flex container) и вложенных элементов (flex items). При активации display: flex все непосредственные дочерние элементы становятся flex-элементами и начинают подчиняться правилам двух осей:

Главная ось (Main Axis)

Направление, вдоль которого по умолчанию выстраиваются элементы. Задается свойством flex-direction (по умолчанию слева направо для row).

Поперечная ось (Cross Axis)

Перпендикулярное направление к главной оси. Используется для выравнивания высоты или вертикального положения элементов (для row направлена сверху вниз).

Шпаргалка по свойствам контейнера

flex-direction

Определяет главную ось контейнера: row (строка, слева направо), row-reverse (строка справа налево), column (колонка, сверху вниз) или column-reverse (колонка снизу вверх).

justify-content

Распределяет свободное пространство вдоль главной оси: flex-start (в начале), flex-end (в конце), center (по центру), space-between (крайние элементы прижаты к бокам), space-around (одинаковые отступы вокруг) или space-evenly (равные расстояния между всеми элементами и краями).

align-items

Выравнивает элементы вдоль поперечной оси: stretch (растягивает на всю высоту), flex-start / flex-end (в начало или конец оси), center (по центру) или baseline (по базовой линии текста).

flex-wrap

Определяет, будут ли элементы сжиматься, пытаясь уместиться в одну линию (nowrap), или перенесутся на новые строки (wrap / wrap-reverse), когда свободного места в контейнере не останется.

Свойства отдельных элементов (Flex Items)

Помимо настроек общего контейнера, вы можете управлять поведением каждого элемента индивидуально с помощью следующих свойств:

flex-grow

Определяет коэффициент «жадности» элемента: пропорцию, в которой он будет увеличиваться, поглощая свободное место в контейнере, если оно есть. По умолчанию равен 0.

flex-shrink

Задает способность элемента сжиматься, когда места в контейнере становится недостаточно. По умолчанию равен 1 (все элементы сжимаются в равной степени).

flex-basis

Базовый начальный размер элемента перед распределением свободного пространства. Может задаваться в px, %, rem или принимать значение auto.

align-self

Позволяет переопределить общее правило выравнивания align-items только для одного конкретного элемента, выбивая его из общего ряда.

В реальной верстке рекомендуется вместо трех отдельных свойств писать компактное объединенное свойство: flex: [flex-grow] [flex-shrink] [flex-basis]. Например, значение flex: 1 0 auto; означает, что элемент может расти, не будет сжиматься меньше своего базового авто-размера.
