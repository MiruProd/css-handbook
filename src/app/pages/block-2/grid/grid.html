15. Grid Layout

CSS Grid Layout — это мощная двухмерная система сеток, которая позволяет одновременно управлять как колонками (вертикально), так и строками (горизонтально), формируя любые сложные интерфейсы сайтов.

Основные концепции CSS Grid

В отличие от Flexbox, который предназначен для одномерных раскладок (выстраивание блоков либо в одну строку, либо в одну колонку), CSS Grid создавался как **полноценный двухмерный инструмент**. Он позволяет разделять страницу на пересекающиеся столбцы и строки, привязывая контент к получившимся ячейкам.

Flexbox (1D Layout)

Выравнивает элементы вдоль одной выбранной оси (главной). Если элементы переносятся на новую строку (flex-wrap), строки не зависят друг от друга, и ячейки во второй строке не выравниваются по первой.

CSS Grid (2D Layout)

Управляет строками и колонками одновременно. Элементы жестко привязываются к пересечениям сетки (сетка первична, контент вторичен), формируя ровные столбцы по всем строкам.

Уникальные инструменты разметки Grid

Для создания гибких сеток в CSS Grid используются уникальные математические функции и единицы измерения:

Фракционная единица (1fr)

Специальная единица измерения fr (fraction) представляет собой одну долю от всего свободного пространства контейнера. Шаблон 1fr 2fr 1fr разделит контейнер на 4 равные части, отдав центральной колонке половину всей ширины родителя.

Функция repeat(кол-во, размер)

Избавляет от необходимости дублировать одинаковые значения. Вместо grid-template-columns: 1fr 1fr 1fr 1fr можно написать компактное и читаемое правило: repeat(4, 1fr).

Функция minmax(min, max)

Задает ячейкам «резиновый» диапазон размеров. Например, minmax(100px, 1fr) означает, что колонка будет плавно сжиматься или растягиваться вместе с экраном, но никогда не станет уже физического порога в 100px.

Адаптивность без медиа-запросов (auto-fit)

Конструкция repeat(auto-fit, minmax(100px, 1fr)) заставляет браузер самостоятельно рассчитывать, сколько колонок шириной не менее 100px помещается в текущем окне, и автоматически переносить ячейки без использования сложных медиа-запросов @media.

Выравнивание внутри ячеек Grid

Каждая ячейка в сетке Grid является микро-контейнером. Вы можете управлять положением элементов внутри ячеек:

justify-items

Выравнивает содержимое всех ячеек по горизонтали (вдоль оси строк): stretch (растянуть во всю ширину), start (прижать влево), end (прижать вправо) или center (выровнять по центру).

align-items

Выравнивает содержимое всех ячеек по вертикали (вдоль оси столбцов): stretch (растянуть во всю высоту), start (прижать к верху), end (прижать к низу) или center (выровнять по центру).
