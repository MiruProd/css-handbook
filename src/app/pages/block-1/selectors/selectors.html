Шпаргалка: Сложные селекторы и комбинаторы

Комбинаторы связывают селекторы между собой, описывая точные отношения между ними внутри структуры HTML-страницы.

1. Потомок (Пробел) A B

Выбирает элемент B на любом уровне вложенности внутри родителя A.

.card span {{ '{' }} color: red; {{ '}' }}
/* Выберет span даже внутри вложенных блоков */

2. Прямой потомок (Дочерний) A > B

Выбирает элемент B, только если он является непосредственным (первым) наследником A.

.card > span {{ '{' }} color: green; {{ '}' }}
/* Не затронет span, если он обернут в другой тег внутри .card */

3. Соседний селектор A + B

Находит элемент B, если он идет сразу же после A на одном уровне вложенности.

h2 + p {{ '{' }} font-weight: bold; {{ '}' }}
/* Идеально для выделения первого вводного абзаца статьи */

4. Родственный селектор A ~ B

Выбирает все элементы B, идущие после A на одном уровне, не обязательно вплотную.

h2 ~ p {{ '{' }} color: gray; {{ '}' }}
/* Выберет все последующие абзацы в пределах секции */

Нативная вложенность (CSS Nesting)

Начиная с 2023–2024 годов, нативная вложенность поддерживается всеми современными браузерами [2]. Это позволяет писать чистые вложенные правила, группируя стили компонента в одном месте.

Как писали раньше (Традиционный CSS)

.menu {{ '{' }}
  background-color: #333;
{{ '}' }}
.menu .menu-item {{ '{' }}
  color: #fff;
{{ '}' }}
.menu .menu-item:hover {{ '{' }}
  color: #ffcc00;
{{ '}' }}

Как пишем сейчас (Современный CSS Nesting)

.menu {{ '{' }}
  background-color: #333;

  .menu-item {{ '{' }}
    color: #fff;

    &:hover {{ '{' }}
      color: #ffcc00;
    {{ '}' }}
  {{ '}' }}
{{ '}' }}

Таблица расчета специфичности (приоритета)

Когда к одному элементу применяются разные стили, браузер рассчитывает «вес» (специфичность) каждого селектора. Побеждает правило с наибольшим весом.

Селектор / Конструкция Пример Очки специфичности (Вес) Приоритет
Директива !important color: red !important; Перебивает всё (Абсолютный) Высший 🏆
Инлайновые стили (атрибут style) <div style="color: red;"> [1, 0, 0, 0] Очень высокий
Идентификаторы (ID) #special-paragraph [0, 1, 0, 0] Высокий
Классы, псевдоклассы, атрибуты .text-highlight, :hover, [type] [0, 0, 1, 0] Средний
Теги и псевдоэлементы p, h3, ::before [0, 0, 0, 1] Низкий
Универсальный селектор / комбинаторы *, +, >, ~ [0, 0, 0, 0] Нулевой

Частая ошибка новичков — использование ID (#header) для стилизации элементов или злоупотребление !important. Из-за этого «вес» селектора становится огромным, и когда вам понадобится изменить цвет кнопки на одной конкретной странице, вам придется писать ещё более сложные селекторы. Стройте верстку преимущественно на классах (очки 0,0,1,0) — их вес сбалансирован и предсказуем.
